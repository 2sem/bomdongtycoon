# Dot sprite manifest

Generated by `tools/dotart/build.py` — do not edit by hand.

- Image name = `dot_<group>_<name>[_<frame>]`, in `Resources/Assets.xcassets/Dot/<Group>/` (folders are not namespaced). One art pixel = one PNG pixel, 1x universal; always `filteringMode = .nearest`.
- **Anchor** is the art pixel (x right, y down, top-left origin) that sits on the ground point. **anchorPoint** is the same thing in SpriteKit units (origin bottom-left): x = (ax + 0.5) / w, y = 1 - (ay + 1) / h.
- Light is top-left; outlines are `ink` (#2b1b2e), never black.
