BomDongTycoon is an iOS game app built with Tuist. Project.swift defines app target `BomDongTycoon` plus framework targets `GameCore` and `GameUI`, with unit test target `GameCoreTests`. iOS deployment target is 17.0. Dependencies include GoogleMobileAds and FirebaseMessaging. Source layout: Sources/App (app layer), Sources/GameCore (core game logic), Sources/GameUI (UI layer), Tests/GameCoreTests (unit tests).
